# Ask the Grid MCP

Ask the Grid connects compatible AI clients to live and historical U.S. power-market data, grid assets, alerts, saved work, and Energy Wire.

## Connect

Use the remote Streamable HTTP endpoint:

```text
https://mcp.askthegrid.com/v1/global
```

Authentication uses OAuth 2.1 authorization code flow with PKCE. An Ask the Grid account is required; public catalog, grid, market, profile, alert, saved-work, and Energy Wire capabilities are available with a free account, subject to product limits.
